# AGENTS.md

이 폴더(ax-day)에서 일하는 에이전트가 지키는 규칙.

- 항상 한국어로 답한다.
- 새 과제는 먼저 단계별 계획을 보여주고, 확인을 받은 뒤 작업한다.
- 결과 파일은 work/ 폴더 안에만 만든다. Pages 첫 화면용 index.html 만 폴더 맨 위에 둔다.
- data/ 와 Scanner.md 같은 원본 파일은 수정하지 않는다.
- 외부 인터넷은 없다. 라이브러리는 lib/ 폴더에 있는 파일만 쓴다 (예: lib/three.min.js).
- 숫자를 계산하는 코드는 Scanner.md 의 검산용 값과 비교해 확인한다.
- 모르는 파일 이름이나 테이블 이름은 추측하지 말고 물어본다.
- 기능 하나가 잘 되면 "커밋할까요?" 라고 먼저 묻는다. 커밋 메시지는 한 일을 한 줄로 쓴다.
- 원격 저장소는 github.samsungds.net 만 쓴다. github.com 에 push 하지 않는다.
- data/ 폴더와 비밀번호·키가 든 파일은 커밋하지 않는다 (.gitignore 에 넣는다).

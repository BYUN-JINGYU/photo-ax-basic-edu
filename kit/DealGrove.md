# 딜-그로브(Deal-Grove) 산화 모델

실리콘 웨이퍼를 고온 로(furnace)에 넣고 산소(건식) 또는 수증기(습식)를 흘리면, 표면의 실리콘이 산소와 반응해 이산화규소(SiO₂) 막이 자란다. 이 막의 두께가 시간과 온도에 따라 어떻게 커지는지를 1965년 Deal과 Grove가 식 하나로 정리했다.

## 1. 기본 식

산화막 두께를 x (μm), 산화 시간을 t (시간, h)라 하면

```
x² + A·x = B·(t + τ)
```

- **B** : 포물선 속도 상수 (μm²/h). 산소가 이미 생긴 산화막을 뚫고 실리콘 표면까지 확산하는 속도를 나타낸다.
- **B/A** : 선형 속도 상수 (μm/h). 산소가 실리콘과 반응하는 속도를 나타낸다.
- **A** : B ÷ (B/A) 로 구한다 (μm).
- **τ** : 처음부터 있던 얇은 산화막을 시간으로 환산한 보정값 (h).

두께를 바로 구하는 꼴로 풀면

```
x = (A / 2) · ( √( 1 + 4·B·(t + τ) / A² ) − 1 )
```

### 두 가지 영역

- 막이 얇을 때 (x ≪ A): x ≈ (B/A)·(t + τ). 시간에 비례해 자란다. **반응 속도가 성장을 결정한다.**
- 막이 두꺼울 때 (x ≫ A): x ≈ √(B·t). 시간의 제곱근에 비례해 자란다. **산소 확산이 성장을 결정한다.**

처음에는 빠르게, 나중에는 점점 느리게 자라는 이유가 여기에 있다.

## 2. 온도에 따른 상수 (아레니우스 식)

```
B   = C₁ · exp( −E₁ / (k·T) )
B/A = C₂ · exp( −E₂ / (k·T) )
```

- k = 8.617 × 10⁻⁵ eV/K (볼츠만 상수)
- T = 섭씨 온도 + 273.15 (켈빈)

| 분위기 | C₁ (μm²/h) | E₁ (eV) | C₂ (μm/h) | E₂ (eV) | 초기 산화막 xᵢ |
|---|---|---|---|---|---|
| 건식 O₂ | 7.72 × 10² | 1.23 | 6.23 × 10⁶ | 2.00 | 0.025 μm |
| 습식 H₂O | 3.86 × 10² | 0.78 | 1.63 × 10⁸ | 2.05 | 0 |

(실리콘 (111) 면 기준. (100) 면은 B/A 를 1.68 로 나눈다.)

τ 는 초기 산화막 xᵢ 로부터

```
τ = ( xᵢ² + A·xᵢ ) / B
```

## 3. 계산 순서 (코드로 옮길 때)

1. T(K) = 온도(°C) + 273.15
2. B 와 B/A 를 아레니우스 식으로 계산
3. A = B ÷ (B/A)
4. τ = (xᵢ² + A·xᵢ) ÷ B
5. x = (A/2)·(√(1 + 4·B·(t+τ)/A²) − 1)
6. 단위: x 는 μm. 화면에는 nm (× 1000) 로 표시하면 읽기 쉽다.

## 5. 시뮬레이터에 넣으면 좋은 범위

- 온도 슬라이더: 800 ~ 1200 °C (기본 1000 °C)
- 시간 슬라이더: 0 ~ 10 h (기본 1 h)
- 분위기: 건식 / 습식 전환 (기본 건식)
- 3D 표현: 실리콘 기판은 회색 큐브, 산화막은 그 위에 얹힌 반투명 파란 층. 층의 높이를 두께에 비례시킨다. 실제 두께는 기판에 비해 매우 얇으므로 보기 좋게 **과장 배율**을 쓰고 화면에 배율을 적어 둔다.

## 6. 개선 아이디어

- 건식 / 습식 전환 버튼
- 두께 vs 시간 그래프 (같은 온도에서 곡선이 점점 완만해지는 것을 보여준다)
- 900 / 1000 / 1100 °C 프리셋 버튼
- 결과 기록표: "기록" 버튼을 누르면 온도·시간·두께가 표에 한 줄씩 쌓인다
- 실제 산화막 색 표현: 산화막은 두께에 따라 간섭색이 달라진다. 예: 약 50 nm 황갈색, 100 nm 짙은 보라, 150 nm 하늘색, 200 nm 금색, 300 nm 보라, 400 nm 청록. 두께 구간에 따라 층 색을 바꿔 본다.
- 카메라 회전 (마우스 드래그)
- 로(furnace) 분위기 연출: 온도가 높을수록 배경을 붉게
- (더 해 보고 싶은 사람) 포토 연결: 지금 두께의 산화막이 ArF(193 nm) 노광 때 기판 반사율을 얼마로 만드는지 (7절)

## 7. 포토 엔지니어를 위한 덧붙임: 산화막 두께와 193 nm 반사율

산화막 위에 레지스트를 바로 올리고 ArF(193 nm)로 노광한다고 하자 (BARC 없음, 수직 입사).
레지스트 → 산화막 → 실리콘으로 빛이 들어갈 때, 레지스트 쪽으로 되돌아오는 반사율 R 은 박막 간섭 식으로 구한다.

```
r01 = (n0 − n1) / (n0 + n1)          # 레지스트 / 산화막 경계
r12 = (n1 − n2) / (n1 + n2)          # 산화막 / 실리콘 경계 (n2 는 복소수)
β   = 2π · n1 · d / λ                # 산화막 한 번 지날 때의 위상
r   = (r01 + r12·e^(2iβ)) / (1 + r01·r12·e^(2iβ))
R   = |r|²
```

| 기호 | 값 (λ = 193 nm) | 뜻 |
|---|---|---|
| n0 | 1.70 | ArF 레지스트 굴절률 (흡수 무시) |
| n1 | 1.5603 | SiO₂ 굴절률 |
| n2 | 0.883 + 2.778i | 실리콘 복소 굴절률 |
| d | 딜-그로브로 계산한 두께 (nm) | 산화막 두께 |

검산용 값 (위 상수 그대로, 소수 첫째 자리 반올림):

| 산화막 두께 d | 반사율 R |
|---|---|
| 0 nm (산화막 없음) | 58.3 % |
| 20 nm | 62.3 % (최대 근처) |
| 52 nm | 57.0 % (최소 근처) |
| 70 nm (1000 °C · 1 h · 건식) | 60.4 % |

- R 은 두께 λ / (2·n1) ≈ **61.8 nm** 마다 한 번씩 출렁인다 (스윙).
- SiO₂ 굴절률이 레지스트와 비슷해서 출렁임은 57~62 % 로 작다. 반사의 대부분은 실리콘 자체에서 온다.
- 그래서 산화막 두께로는 반사를 줄일 수 없고, 반사를 잡으려면 **BARC** 가 필요하다.

## 8. 용어

| 용어 | 뜻 |
|---|---|
| 열산화 (thermal oxidation) | 고온에서 실리콘 표면에 SiO₂ 막을 키우는 공정 |
| 건식 산화 (dry) | 산소(O₂)로 산화. 느리지만 막질이 좋다 |
| 습식 산화 (wet) | 수증기(H₂O)로 산화. 빠르다. 두꺼운 막에 쓴다 |
| 포물선 속도 상수 B | 확산이 지배하는 구간의 성장 속도 |
| 선형 속도 상수 B/A | 반응이 지배하는 구간의 성장 속도 |

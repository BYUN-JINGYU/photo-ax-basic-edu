# data 폴더

`eqp_alarm.csv` 는 **가상 데이터**입니다. 실제 설비 기록이 아닙니다.
Datalake 접근이 막힌 PC 에서 5장 실습(설비 알람 차트)과 6장 스킬 실습을 할 때 씁니다.

- 컬럼: `alarm_time`(알람 시각), `eqp_id`(설비), `alarm_name`(알람 이름), `stop_min`(멈춘 시간, 분)
- 설비 6대(EQP-01~06), 2026-09-05 ~ 2026-10-02 의 4주, 711행
- 알람 이름 다섯 가지: 도어 열림, 온도 높음, 압력 낮음, 통신 끊김, 센서 점검 필요
- 이야기: EQP-03 은 마지막 한 주에 "온도 높음" 알람이 몰립니다. 나머지 설비는 평소 수준입니다
- 검산값: 10월 1일 하루 EQP-03 은 14건으로 가장 많습니다. EQP-03 의 마지막 7일 합계는 62건입니다
- 요청문에서 "Datalake 에서 가져와줘" 대신 "data/eqp_alarm.csv 를 읽어서" 로 바꿔 쓰면 됩니다

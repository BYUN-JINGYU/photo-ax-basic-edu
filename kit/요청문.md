## 4장 · 딜-그로브 3D 시뮬레이터

```
DealGrove.md파일의 딜-그로브 산화 모델을 완벽히 이해해 줘.
그리고 웹 브라우저에서 실행되는 3D 시뮬레이터를 만들어줘.

화면 한가운데에 Three.js를 사용해서 두꺼운 회색 큐브(실리콘 기판)를 그려.
화면 왼쪽에는 '온도(Temperature)'와 '시간(Time)'을 조절할 수 있는 슬라이더를 만들어.

슬라이더를 움직이면 딜-그로브 수식에 따라 산화막 두께를 계산하고, 회색 큐브 위에 반투명한 파란색 층(산화막)이 그 두께만큼 실시간으로 자라나는 3D 애니메이션을 보여줘.
```

폐쇄망에서는 아래 한 줄을 끝에 덧붙인다.

```
Three.js 는 인터넷 대신 lib/three.min.js 파일을 <script> 로 불러서 써. 결과는 work/simulator.html 한 파일로 만들어줘.
```

## 4장 · 개선 (하나씩)

```
건식 / 습식 전환 버튼을 추가해줘. 전환하면 DealGrove.md 의 습식 상수로 계산해.
```

```
화면 오른쪽에 현재 온도에서 두께 vs 시간 그래프를 그려줘. 0~10 시간 범위, 단위는 nm.
```

```
두께 표시를 nm 단위로 바꾸고, 3D 층의 과장 배율을 화면에 적어줘.
```

```
DealGrove.md 6절의 산화막 간섭색 표를 참고해서, 두께 구간에 따라 파란 층의 색을 바꿔줘.
```

```
슬라이더 위에 900, 1000, 1100 °C 버튼을 만들어줘. 누르면 온도 슬라이더가 그 값으로 바뀌게.
```

```
"기록" 버튼을 누르면 지금 온도·시간·두께가 화면 아래 표에 한 줄씩 쌓이게 해줘.
```

```
마우스로 드래그하면 3D 장면이 돌아가게 해줘. 외부 라이브러리 없이 직접 구현해.
```

```
온도가 높을수록 배경이 붉게 달아오르게 해줘. 800 °C 는 어둡게, 1200 °C 는 주황빛으로.
```

## 5장 · Datalake 설비 알람 데이터 요청

```
사내 Bigdataquery 라이브러리와 Impala SQL 로 Datalake에서 데이터를 가져와줘.
- 무슨 데이터: eqp_alarm 테이블의 알람 시각, 설비, 알람 이름, 정지 시간
- 조건: 최근 4주, 우리 라인 설비
- 결과 형태: work/eqp_alarm.csv 로 저장한 뒤 행 수와 기간 범위를 알려줘
- 상한: 최대 10,000행
- 규칙: SELECT 조회만, 결과 파일은 work 폴더 안에만, 개인정보 컬럼은 제외

실행 전에 사용할 쿼리를 먼저 보여줘.
```

Datalake 에 접근이 안 되면 첫 줄을 "data/eqp_alarm.csv 를 읽어서" 로 바꿔 씁니다.

```
work/eqp_alarm.csv 로 설비별 하루 알람 건수 막대 차트를 report.html 한 파일로 만들어줘.
- 위에서 설비를 고르면 그 설비의 차트로 바뀌게.
- 앞 3주 하루 평균을 "평소" 점선으로 긋고, 평소의 2배가 넘은 날은 빨간 막대로.
- 옆에 이번 주 합계, 평소 한 주와 비교한 %, 많이 난 알람 TOP 3 를 표로.
- 차트는 외부 라이브러리 없이 SVG 로 그려줘. 인터넷 없음.
```

## 8장 · 커밋과 Pages 공유

기능이 잘 될 때마다:

```
커밋해줘.
```

깨졌을 때:

```
마지막 커밋으로 되돌려줘. 무엇이 지워지는지 먼저 알려줘.
```

사내 GitHub 웹에서 빈 저장소 `ax-day` 를 만든 뒤:

```
이 폴더를 git 저장소로 만들어줘. data 폴더는 .gitignore 에 넣어 올리지 마.
맨 위에 index.html 을 만들고 work/simulator.html 로 가는 링크를 넣어줘.
지금 상태를 "딜-그로브 시뮬레이터 첫 버전"으로 커밋해줘.
원격 저장소는 https://github.samsungds.net/<내 아이디>/ax-day 야. github.com 은 쓰지 마.
main 브랜치로 push 하고 git log --oneline 을 보여줘.
```

그다음 저장소의 Settings → Pages 에서 Deploy from a branch · main · / (root) · Save.
